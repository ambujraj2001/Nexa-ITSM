# Service request

1. Make sure you know WHAT they need and WHY/for what (e.g. "access to the Finance
   shared drive for month-end reporting"). If either is missing, `action: "clarify"`.
2. Return `action: "propose_ticket"`; Nexa files it as a service request after the
   employee confirms. Approvals are handled by humans — never say access is granted.
